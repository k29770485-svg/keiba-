# 厳格な期待値ベッティング方針

> **注意:** この方針は、不確実性を大きく見積もって購入候補を大幅に減らすための実装である。期待値・回収率・的中・利益を保証しない。実運用の購入判断は利用者自身の責任で行うこと。

## 変更理由

従来の `sql_pipeline.score_market_data()` は、馬単位の決定論的スコアをソフトマックス正規化し、単勝オッズを掛けた相対期待値が0%以上の馬を買い目候補にしていた。この値は券種の組合せ確率ではなく、控除率・確率推定誤差・小標本の校正誤差を織り込んでいない。そのため、買い目の期待値判定には使わない。

## 新しい買い目判定

買い目は `RaceMarketData.ticket_market_quotes` に含まれる券種別の市場払戻見込みと、同一アルゴリズム版に対する**事前ウォークフォワード校正済み確率**を使う。

1. 予測対象の組合せに欠損特徴量が1つでもあれば見送る。
2. 校正済み精算件数が `VALUE_MIN_CALIBRATION_SAMPLE_SIZE` 未満なら見送る。既定は250件。
3. 正規近似の95%下方信頼限界を求める。`p_lcb = max(0, p - 1.96 * sqrt(p(1-p)/n))`。
4. 券種別にJRA設定払戻率を使う。ワイド77.5%、3連複75.0%、3連単72.5%。
5. 発走前払戻見込みから控除前倍率を復元し、控除後の保守的期待値を計算する。

```text
net_multiple      = payout_per_100_yen / 100
p_lcb             = 校正済み確率の下方信頼限界
gross_multiple    = net_multiple / JRA払戻率
gross_edge        = p_lcb * gross_multiple - 1
conservative_ev   = p_lcb * gross_multiple * JRA払戻率 - 1
```

既定では、`gross_edge >= 50%` かつ `conservative_ev >= 35%` の両方を満たす必要がある。さらに、1レースにつき最大1点である。市場払戻見込み、校正済み確率、校正件数、モデル版のいずれかが不足すれば、投資額0円の見送りとなる。

## 穴馬表示

穴馬ラベルは、単勝相対期待値75%以上、人気6番手以下、オッズ5倍以上、かつスコア用特徴量の欠損なしの場合だけ付与する。ラベルは買い目の根拠ではなく、買い目には上記の券種別条件を別途満たす必要がある。

## 直近2週間の扱い

直近2週間だけの精算結果は、既定の250件校正条件を満たさない限り買い目に使わない。結果が良かった日だけで閾値を下げない。校正件数を変更する場合も、学習期間と評価期間を分離した時系列ウォークフォワード検証を先に実施し、券種・会場・馬場別に十分な母数があることを確認する。

## 入力契約

`ticket_market_quotes` の各行に次を保存する。

| 項目 | 意味 |
| --- | --- |
| `ticket_type` | `wide`、`trio`、`trifecta` のいずれか |
| `selection` | 組合せの馬番。3連単は着順順、他は昇順で正規化する |
| `payout_per_100_yen` | 発走前の100円あたり払戻見込み。確定払戻ではない |
| `calibrated_probability_pct` | 同一アルゴリズム版で校正済みの組合せ的中確率 |
| `calibration_sample_size` | 発走時点までに確定したウォークフォワード精算件数 |
| `model_version` | 校正確率を生成したアルゴリズム版。予想実行版と一致必須 |

JRA設定払戻率は公式の馬券ルールに基づく。[1]
