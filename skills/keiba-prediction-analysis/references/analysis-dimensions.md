# 予想外れ原因の分析観点

## 必須分析軸

1. **日別的中率推移** — 急落のタイミングを特定
2. **予想vs実際の突合** — 3頭中何頭が3着以内に入ったか（overlap分析）
3. **会場別** — 特定の競馬場で弱いか
4. **馬場状態別** — 重馬場で外しやすいか
5. **3連単配当分析** — 万馬券率が高い日は構造的に外れる
6. **アルゴリズム診断** — analysisJsonのスコア内訳（baseScore/courseBonus/historyBonus/aptitudeBonus比率）

## 荒れ判定基準

| 指標 | 通常 | やや荒れ | 大荒れ |
|------|------|----------|--------|
| 万馬券率 | <20% | 20-50% | >50% |
| 平均3連単 | <5万 | 5-20万 | >20万 |
| 予想◎3着以内率 | >40% | 20-40% | <20% |

## アルゴリズム健全性チェック

- baseScore比率 > 80%: **オッズ依存過多**（人気馬しか選べない）
- courseBonus = 0: コース適性未実装
- historyBonus = 0: 過去成績未活用
- aptitudeBonus = 0: 適性データ未反映

## 改善提案テンプレート

原因特定後、以下の優先度で改善を提案:

1. 高: 過去成績(horse_race_history)から同コース・同距離の成績をhistoryBonusに反映
2. 高: 脚質×コース形態の相性をcourseBonusに反映
3. 中: レースクラス別の荒れやすさ係数を導入
4. 中: 騎手の当該コース成績を加味
5. 低: 馬場状態での過去成績ボーナス
6. 低: 前走間隔・調教状態の考慮
