# EV算出根拠の透明化

EVを能力評価と混同せず、入力値・計算式・欠損理由を利用者に確認可能な状態で表示する。

## 実装手順

1. **計算源を固定する。** サーバー側でEV、推定勝率、使用オッズを同じ計算関数から返す。UI側でEVを再計算しない。
2. **能力と市場を分離する。** 能力スコア、推定勝率、オッズ、EVを別フィールド・別カラムで返す。市場オッズを能力スコアへ混在させない。
3. **欠損を保持する。** オッズが未取得・0・不正、または推定勝率が未算出ならEVを`null`にする。0%や負のEVへ置き換えない。
4. **EV表示を明確にする。** EVが負なら警告アイコンを付け、正・負・未算出を色とテキストで区別する。
5. **説明ツールチップを付ける。** EVセルのヘルプアイコンへ、以下を表示する。
   - 計算式: `（推定勝率 ÷ 100 × 単勝オッズ − 1）× 100`
   - 使用した推定勝率と単勝オッズ
   - 計算されたEV
   - 推定勝率が相対指標であり、結果を保証しない旨
   - 未算出時は具体的な不足項目と「推測で補完しない」旨
6. **アクセシブルにする。** ツールチップのトリガーは`button`にし、`aria-label`を付ける。ホバーだけでなくキーボードフォーカスでも内容を確認可能にする。

## 安全な表示ルール

| 状態 | 表示 | ツールチップ内容 |
|---|---|---|
| EV > 0 | 正の数値 | 入力値・式・計算結果 |
| EV < 0 | 警告アイコン付きの負の数値 | 入力値・式・計算結果・注意表示 |
| EV = 0 | 0.0% | 入力値・式・計算結果 |
| EV未算出 | `未算出` | 欠損項目と未補完の理由 |

## 検証

1. 正のEV、負のEV、オッズ欠損、推定勝率欠損を単体テストする。
2. 型検査と既存の予想・精算テストを実行する。
3. 中央・地方それぞれの予想画面で、EV列・警告・ツールチップが崩れないことを確認する。
4. 実オッズが未取込の場合は、判定が`未算出`となることを確認する。テスト用・推測値を保存しない。

## 実装上の注意

- 予測モデルの非公開詳細や重みをツールチップへ表示しない。利用者に必要な計算入力と式だけを示す。
- EVは回収や的中を保証する指標として表現しない。
- 組合せ馬券のリスク判定は、単勝EVとは別に公式の組合せオッズで処理する。
