# netkeiba 競走成績スクレイピング仕様

## 対象ページ

馬のプロフィールページ: `https://db.netkeiba.com/horse/{netkeibaId}`

## HTMLテーブル構造

競走成績は `table.db_h_race_results` 内の `<tbody>` にある各 `<tr>` が1レース分。

## パース時の注意点

- `cells[i]` が `undefined` の場合がある（古いレースでカラム数が異なる）
- 距離カラムは `芝1600` / `ダ1200` / `障3000` 等のパターン
- 馬体重は `480(+4)` / `480(-2)` / `480(0)` / `計不` 等
- 着順が数字以外（"中止", "除外", "取消"）の場合もそのまま保存
- raceIdはレース名リンクの `href` から `/race/(\d+)/` で抽出
- 写真URLは `div.horse_photo img` の `src` 属性

## レート制限対策

- 1馬あたり最低2秒の待機を推奨
- 1回のバッチで最大20頭程度に制限
- User-Agentヘッダーを設定
- 429レスポンス時は指数バックオフ
